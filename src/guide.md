## 快速上手

### 界面一览

TizuMark 的界面分为以下区域：

| 区域 | 位置 | 说明 |
|------|------|------|
| **顶部工具栏** | 顶部 | 文件 / 帮助菜单，视图（预览/编辑）切换，重新加载、主题、窗口控制；侧边栏由左缘悬浮把手开合 |
| **格式工具栏** | 顶部下方 | 常用排版按钮与复合下拉，可折叠 |
| **侧边栏** | 左侧 | 文件树（上）与大纲（下），可拖拽调整上下比例 |
| **编辑区** | 中部 | CodeMirror 编辑器，Markdown 语法高亮、括号与引号自动配对；顶部有面包屑导航 |
| **预览区** | 右侧 | 实时渲染 Markdown，同步滚动 |
| **状态栏** | 底部 | 字数 / 行数 / 光标行列 |

### 基本操作

| 操作 | 方法 | 快捷键 |
|------|------|--------|
| 新建文件 | `文件 → 新建` | <kbd>Ctrl</kbd> + <kbd>N</kbd> |
| 打开文件 | `文件 → 打开`（支持批量选择） | <kbd>Ctrl</kbd> + <kbd>O</kbd> |
| 打开文件夹 | `文件 → 打开文件夹` | — |
| 保存文件 | `文件 → 保存` | <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| 另存为 | `文件 → 另存为` | — |
| 重新加载 | `文件 → 重新加载`（放弃改动，从磁盘重读） | — |
| 打开最近的文件 | `文件 → 打开最近的文件` | — |
| 打开最近的工作区 | `文件 → 打开最近的工作区` | — |
| 快捷键设置 | `文件 → 快捷键设置` | — |
| 设置 | `文件 → 设置` | — |
| 命令行打开 | `TizuMark.exe 文档.md` | — |
| 关闭标签 | 点击标签 × 或右键菜单 | <kbd>Ctrl</kbd> + <kbd>W</kbd> |

> 直接将 `.md` 文件**拖入窗口**即可打开，支持多文件拖放。`文件 → 打开最近的文件` 可快速回到之前编辑的文档，`文件 → 打开最近的工作区` 可快速回到之前打开的文件夹工作区。

## 编辑器功能

### 视图模式

TizuMark 会根据文件类型自动选择最合适的视图，无需手动配置：

- **Markdown（`.md` 等 7 种扩展名）**：支持 **预览模式**（全屏渲染，适合阅读和演示）与 **编辑模式**（左写右览，所见即所得）。编辑模式下可点 **◄**（左侧）折叠编辑器、点 **►**（右侧）折叠预览，让另一侧独占屏幕；拖动中间分隔条可调整左右比例。
- **纯文本 / 代码（.txt 及非 Markdown 文本）**：自动进入**纯编辑视图**——只有编辑器、没有预览栏，也不会出现折叠 / 展开按钮（这类文件没有可渲染的预览）。
- **图片**：自动进入**预览（只读）视图**——只显示图片本身，不能切换到编辑。

> 若对纯文本点「预览」、或对图片点「编辑」，会弹提示：该文件类型不支持对应模式。

工具栏中间的两个标签可切换视图；<kbd>Ctrl</kbd> + <kbd>\\</kbd> 也可切换——它对任何文件都能按，但只有 Markdown 会真的切换，纯文本和图片会提示不支持该模式。在编辑模式下：

| 操作 | 方法 |
|------|------|
| 折叠编辑器 | 点击左侧 <kbd>◄</kbd> 按钮 |
| 折叠预览 | 点击右侧 <kbd>►</kbd> 按钮 |
| 调整比例 | 拖动中间分隔条 |

### 侧边栏：文件与大纲

点击窗口左缘垂直居中的悬浮把手可显示或隐藏侧边栏。侧边栏上下分为「文件」「大纲」两块，中间的分隔条可拖拽调整上下比例，两块面板也可各自收起。

**文件面板**（使用 `文件 → 打开文件夹` 打开目录后显示）：

- 顶部显示工作区路径，右侧是**排序**控件（名称 / 修改时间 / 创建时间，旁边按钮切换升序 / 降序）与「关闭文件夹」。
- 面板头有「展开 / 折叠全部目录」按钮。
- 点击文件即在标签页打开；目录树会监听文件夹的外部增删变化并自动刷新。
- **右键菜单**：新建文件（<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>N</kbd>）/ 新建文件夹（<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd>）/ 剪切 / 复制 / 粘贴 / 重命名（<kbd>F2</kbd>）/ 复制路径 / 打开所在目录 / 删除（<kbd>Delete</kbd>）。
- 默认只列出软件能识别的格式；如需显示目录内全部文件，可在 `设置 → 行为 → 显示所有文件` 中开启。

**大纲面板**：

- 自动显示文档标题结构（H1 ~ H6），按层级缩进。**点击任意标题**，预览区自动跳转并居中；大纲随编辑实时更新。
- 面板头部的**层级过滤**下拉可只显示到指定层级（全部 / H1 ~ H6）；「展开 / 折叠全部大纲」按钮可一键展开或收起。

### 编辑器面包屑

编辑器顶部会显示 `文件名 › 当前标题…` 的层级路径，随光标位置实时更新。点击任一层级即可跳转；层级过长时可横向滚动。

### 多标签页

| 操作 | 方法 |
|------|------|
| 新建标签 | 点击标签栏 <kbd>+</kbd> 或 <kbd>Ctrl</kbd> + <kbd>N</kbd> |
| 切换标签 | <kbd>Ctrl</kbd> + <kbd>Tab</kbd> / <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| 拖拽排序 | 直接拖拽标签调整顺序 |
| 关闭标签 | 点击 × 或 <kbd>Ctrl</kbd> + <kbd>W</kbd> |
| 右键菜单 | 关闭 / 关闭其他 / 关闭所有 / 复制文件路径 / 打开所在目录 |
| 双击新建 | 标签栏空白处双击 |

标签较多放不下时，标签栏两端会出现左右滚动箭头，点击即可横向滚动。

已修改未保存的标签会显示 `*` 标记。

**会话恢复**：关闭 TizuMark 后重新打开，上次的标签页、文件夹工作区、展开的目录都会自动恢复，接续之前的工作状态（可在设置中改为「退出时关闭所有标签」，让每次启动都从空白开始）。

### 查找与替换

查找相关的入口有四个，各司其职。**前两个是文档内查找**（分别在编辑区和预览区），**后两个是跨文件与文件速达**：

**编辑器查找替换**（<kbd>Ctrl</kbd> + <kbd>F</kbd>）：在当前文档的源码中查找，替换功能也在同一个面板里。

| 功能 | 说明 |
|------|------|
| 普通查找 | 输入关键词，点击下一个 / 上一个，并显示匹配数量 |
| 替换 | 输入新内容，点击替换或全部替换 |
| 区分大小写 | 精确匹配大小写 |
| 正则表达式 | 支持 JavaScript 正则语法 |
| 循环查找 | 到文档末尾后回到开头继续查找 |

**预览查找**（预览模式下 <kbd>Ctrl</kbd> + <kbd>F</kbd>）：在渲染后的内容中搜索并高亮定位。

**跨文件搜索**（<kbd>Ctrl</kbd> + <kbd>H</kbd>）：可在当前所有打开标签或指定目录中搜索，含正则与区分大小写选项。搜索结果按文件分组、显示行号列号与上下文片段，点击即跳转并在编辑区与预览区同时高亮。适合在大型项目文档中快速定位。

**文件搜索**（<kbd>Ctrl</kbd> + <kbd>P</kbd>）：在工作区中按文件名或路径快速跳转（VS Code 风格 Quick Open）。弹出面板后输入关键字即时筛选，匹配当前工作区内的 `.md` / `.markdown` / `.txt` 文件，↑/↓ 选择、<kbd>Enter</kbd> 打开、<kbd>Esc</kbd> 或点击面板外关闭；新建的文件在窗口重新获得焦点后会即时出现在列表中。

### 右键菜单

几处右键菜单，减少鼠标往返：

- **编辑区右键**：剪切 / 复制 / 粘贴 / 结构插入 / 文本格式 / 列表 / 链接与媒体 / 查找替换 / 全选
- **预览区右键**：复制 / 全选 / 复制为 HTML / 在预览中查找
- **标签页右键**：关闭 / 关闭其他 / 关闭所有 / 复制文件路径 / 打开所在目录
- **文件树右键**：见上文「侧边栏 → 文件面板」

### 外部文件变更提示

当打开的文件在 TizuMark 之外被其他程序修改时，顶部会弹出提示横幅，提供「重新加载」「忽略」「全部重新加载」「全部忽略」选项，避免误覆盖你的修改。

### 大文档保护

当文档超过约 **5000 行**或约 **400 万字符**时，预览会自动切换为滑动窗口模式，只渲染当前阅读区域附近的内容（约 1200 行的窗口），而非整篇一次性解析——因此数万行甚至更大的文档也能流畅打开。切换时编辑区顶部会出现提示横幅，可点「不再提醒」在本会话内静音，或「关闭」收起。

### 状态栏

窗口底部状态栏实时显示当前文档的 **原始字数**、**预览字数**、**行数**，以及光标所在的**行、列**位置，随编辑即时更新，方便随时掌握写作进度。

## 插入功能详解

### 快捷插入（「/」命令）

在编辑器中输入「/」会弹出快捷插入列表，用方向键选择、回车即可插入常见语法块（标题、代码块、表格、提示块、公式、Mermaid、目录等），无需记忆语法。

- **打开**：在行首、或前一个字符是空格（含行中间的空格之后）输入 `/` 即弹出列表；继续输入关键字可实时过滤（如 `/table`、`/toc`、`/callout`）。
- **选择**：<kbd>↑</kbd> / <kbd>↓</kbd> 移动，<kbd>Enter</kbd> 插入，<kbd>Esc</kbd> 关闭。
- **自定义**：在 `文件 → 设置 → 快捷插入 → 管理快捷插入…` 中可拖动调整各项顺序、取消勾选隐藏不常用的项，让列表更贴合你的习惯。

### 结构插入

| 元素 | 插入内容 |
|------|----------|
| 标题 H1 ~ H6 | `#` ~ `######` 前缀标题 |
| 代码块 | ` ``` ` 包围的代码块（支持 JavaScript / Python / Rust / HTML / CSS / YAML / Shell 等语法高亮） |
| 表格 | 3×3 基础表格模板 |
| 引用块 | `>` 前缀引用段落 |
| 提示块 | Note / Tip / Warning / Caution / Important |
| Admonition | `!!! note "标题"` 提示块；Admonition 折叠插入 `??? warning "点击展开"` |
| 数学公式 | `$$` 包围的独立公式（KaTeX 渲染） |
| 编号公式 | 带 `\label{}` 的公式块，可按章节自动编号（见设置「公式按章节编号」） |
| 物理量 (siunitx) | `$\SI{...}{...}$` 物理量模板 |
| Mermaid 图表 | 流程图 / 时序图等模板 |
| PlantUML / D2 图 | PlantUML / D2 语法模板（自动转换为 Mermaid 渲染） |
| TikZ 绘图 | TikZ 常用子集模板 |
| 函数绘图 | `plot sin(x)` 形式的函数图像模板 |
| 思维导图 | ` ```markmap ` 缩进大纲模板 |
| 水平线 | `---` 分割线 |
| 目录 | `[TOC]` 标记，自动生成文档目录 |

> 行内公式使用 `$...$`，独立公式使用 `$$...$$`。公式内容会自动做 HTML 转义，`&`、`<`、`>` 等字符直接书写即可，无需手动写成 `&amp;` 这类实体。

> **化学式与化学方程式**（KaTeX mhchem 扩展）：用 `$\ce{...}$` 写化学式/反应式，`$\pu{...}$` 写物理单位，例如 `$\ce{2H2 + O2 -> 2H2O}$`、`$\ce{H2SO4}$`、`$\pu{123 kJ//mol}$`。反应箭头、上下标、同位素、离子电荷（`$\ce{SO4^2-}$`）等 mhchem 语法均可直接使用；多行反应式用 `$$` 块级公式并配合 `\\` 换行。
>
> **单位写法（siunitx 子集，内置）**：`$\si{...}$` 写单位（符号形式）、`$\SI{数值}{单位}$` 写带数值的完整量，例如 `$\SI{1.2e-3}{m s^-1}$`、`$\si{kJ//mol}$`。单位之间的**空格与 `.` 会渲染成细空格**（`$\si{kg m}$` → kg m），因此请按语义写：`kJ//mol` 是"每"（→ kJ/mol），`kg*m` 是乘法（→ kg·m），`m/s` 原样保留。常用单位宏（`\kilogram`、`\metre`、`\celsius`、`\percent` 等）也可直接写。

### 图表与可视化

用代码块即可画图（无需装任何插件），全部离线渲染、跟随明暗主题重绘、点击可放大：

| 代码块 | 引擎 | 内容写法 |
|--------|------|----------|
| ```` ```mermaid ```` | Mermaid | 流程图 / 时序图 / 甘特图 / 类图 / 状态图 / 饼图 / **脑图 mindmap** |
| ```` ```plantuml ```` | PlantUML → Mermaid | 时序图 / 用例图 / 组件图 / 类图 / 状态图 / 活动图 / 甘特图（`uml` / `puml` / `pu` 为别名）；不支持的分支（`fork` / `split` / `repeat` 等）会保留源码并提示 |
| ```` ```d2 ```` | D2 → Mermaid | D2 的节点/边语法与 `shape` / `style` 等常用属性 |
| ```` ```echarts ```` | ECharts | ECharts 的 option JSON（可选顶层 `tizuHeight` 指定画布高度，默认 360） |
| ```` ```wavedrom ```` | WaveDrom | WaveDrom 的 source JSON（`signal` / `assign` / `reg`；`wave` 为别名） |
| ```` ```dot ```` | Graphviz | DOT 语言描述的节点/边关系图，自动布局（`graphviz` / `gv` 为别名；首行写 `// engine: neato` 可切换布局引擎）；**中文节点名会自动补引号**，可直接写 `来料 -> 检验`（边操作符是 `->`/`--`，不是 Mermaid 的 `-->`） |

| ```` ```plot ```` | gnuplot | 函数绘图，如 `plot sin(x)`，支持 `set xlabel` / `set grid` 等（`gnuplot` 为别名） |
| ```` ```markmap ```` | Markmap | 缩进式 Markdown 大纲 → 思维导图 |

> 语法写错时不会静默空白，而是显示失败原因并保留原始源码，便于就地修改。

### 提示块（Callout）

TizuMark 支持 GitHub 风格的提示块，用于在文档中突出重要信息：

```markdown
> [!NOTE]
> 这是一个普通提示信息。

> [!TIP]
> 这是一个实用建议或技巧。

> [!WARNING]
> 这是一个需要关注的警告信息。

> [!CAUTION]
> 这是一个需要特别注意的风险提示。

> [!IMPORTANT]
> 这是一个至关重要的信息。
```

### Admonition 提示块（扩展语法）

除 GitHub 风格 Callout 外，还支持 MkDocs / Python-Markdown 风格的 Admonition 语法：

```markdown
!!! note "自定义标题"
    这里是提示内容，支持**完整 Markdown** 与嵌套。

??? warning "点击展开"
    默认收起，点击标题才展开。

???+ tip "默认展开"
    折叠块，但默认是展开的。
```

- `!!!` 始终展开，`???` 默认折叠，`???+` 折叠但默认展开；标题可省略（使用类型默认名）或自定义。
- 支持 `note` / `abstract` / `info` / `tip` / `important` / `success` / `question` / `warning` / `caution` / `failure` 等类型；同一配色内互为别名（如 `caution` / `attention` 等同 `warning`）。
- 也可用 `::: note` … `:::` 容器写法。

## 图片管理

TizuMark 提供完善的图片处理能力，支持多种插入方式和自动去重。

### 插入图片

| 方式 | 操作 | 说明 |
|------|------|------|
| 粘贴 | <kbd>Ctrl</kbd> + <kbd>V</kbd> | 在编辑区粘贴剪贴板中的图片（截图、复制的图片文件等），按下方设定的存储方式保存后插入 |
| 插入对话框 | 格式工具栏「图片」按钮，或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>I</kbd> | 可选择本地文件，也可直接填入网络图片 URL |
| 右键菜单 | 编辑区右键 → 插入图片 | 同上 |

> 把图片文件**拖入窗口**是「打开」而不是「插入」——它会以只读预览的方式在新标签页中打开，不会插入当前正在编辑的文档。要插入，请用上面的粘贴或插入对话框。

### 自动去重

同一内容的图片只会存储一份。TizuMark 通过 **MD5 哈希**比对图片内容：

- 粘贴或插入图片时，自动计算文件 MD5
- 如果该图片已存在，直接复用已有文件
- 同名但内容不同的图片不会冲突

### 图片存储方式

可在 `文件 → 设置 → 行为 → 图片存储方式` 中配置：

- **复制到 assets/（推荐）**：图片保存为独立文件，md 文件轻量，便于版本管理
- **Base64 嵌入**：图片编码到 md 文件内，单文件即可分享，但体积显著增大（约原图 1.4 倍）

### 图片存储路径

可在 `文件 → 设置 → 行为 → 图片存储路径` 中配置：

- **相对路径**（默认）：相对于当前 Markdown 文件所在目录
- **绝对路径**：使用设定的固定目录（如 `D:\assets`）

设置下方会动态显示实际的引用路径示例，方便确认。

### 自动宽高属性

以「复制到 assets/」方式插入图片时，会自动附带原始宽高：

```html
<img src="assets/abc123.png" width="800" height="600" alt="示例图片">
```

你可以直接在编辑器中修改或删除 `width`/`height`：

- 改为百分比：`width="100%"`
- 完全删除：预览会按原始尺寸渲染

> 若存储方式选的是「Base64 嵌入」，插入的是 `![描述](data:image/png;base64,...)`，不会附带宽高属性。

### 图片查看器

预览中点击任意图片可弹出专用查看器，**鼠标拖拽**可平移，**滚轮以光标所在位置为锚点缩放**（想放大某个局部，就把鼠标移到那儿再滚），**双击**可重置回适应窗口的状态。无需离开 TizuMark 即可细看大图。

## 导出功能

### 导出 HTML

`文件 → 导出 HTML` 生成独立的 HTML 网页文件：

- 包含完整 CSS 样式
- 表格、代码块、数学公式、Mermaid 图表均保留样式
- 可直接在浏览器中打开分享

### 导出长图

导出为高清 PNG 长截图（宽度固定 800px，高度自适应，支持暗黑主题样式）。**该功能仍保留在代码中，但出于大文档可能占用大量内存的考虑，已从「文件」菜单隐藏**；如需使用请联系我们或使用 HTML / PDF 导出替代。

### 导出 PDF

`文件 → 导出 PDF`（快捷键 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>）通过系统打印对话框导出：

- 弹出提示确认后，使用浏览器原生打印功能
- 在打印对话框中可选择「另存为 PDF」、调整纸张方向/边距等
- Mermaid 图表会重新渲染以保证清晰度；数学公式沿用预览中已渲染的 KaTeX 结果，并内联其样式表

### 导出 DOCX

`文件 → 导出DOCX` 生成标准 `.docx` 文档（Word 2007+ 原生格式，可直接双击用 Word/WPS 打开编辑）：

- 点击后先弹**确认框**（纸张 / 方向 / 边距固定为 A4 / 纵向 / 标准；如需其它页面设置，导出后在 Word「布局 → 页面设置」里调整），确认后开始导出
- 由预览内容转换为**真 OOXML**，套用与预览一致的排版样式（标题层级与分隔线、正文行距、列表、表格边框、引用块、代码块灰底、提示框配色、加粗/斜体、链接、图片等）
- 标题映射为 Word **真标题样式**（导航窗格可识别）；公式转换为 Word 可编辑的 **OMML**（MathML→OMML）
- 图片自动内联为文档内嵌资源（无需附带文件夹），并自动缩放以适配页面宽度，不会因过大被裁切显示不全
- Mermaid 图表在导出前会先渲染为图片再嵌入，并自动缩放到页面宽度，避免 Word 无法识别 SVG 或因图过宽而显示不全
- 已知限制：提示框圆角/阴影、任务列表勾选框等 Word 不支持的 CSS 会被简化；代码块中过长的行可能超出页面边界

## 常见问题

### 如何恢复默认设置？

`文件 → 设置` 或 `文件 → 快捷键设置` 中点击「恢复默认」。

### 支持哪些文件格式？

按打开方式分为三类：

| 类别 | 打开方式 | 格式 |
|------|----------|------|
| **Markdown 类** | 渲染预览，支持编辑 / 预览切换 | `.md` `.markdown` `.mdown` `.mkd` `.mkdn` `.mdwn` `.markdn` |
| **图片类** | 只读预览，不可编辑 | `.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp` `.svg` `.tif` `.tiff` `.ico` `.avif` `.heic` 等 20 种 |
| **明文 / 代码类** | 纯编辑视图（无预览栏），不做 Markdown 渲染 | `.txt` `.log` `.json` `.yaml` `.toml` `.csv` `.html` `.css` `.js` `.ts` `.jsx` `.py` `.rs` `.go` `.java` `.c` `.cpp` `.sh` `.sql` `.xml` `.tex` `.ipynb` 等 145 种 |

不在这份白名单内的后缀会提示「格式不支持」，并且不会被打开（可在设置中开启「显示所有文件」让文件树列出它们）。

### 如何自定义快捷键？

`文件 → 快捷键设置`，点击「修改」后按下新组合键。点击「清除」可移除，点击「恢复默认」可还原。

### 帮助菜单里为什么没有「检查更新」？

本分支已停用自动更新，应用完全离线运行、不会联网检查版本。需要升级时请手动下载新版本安装包。

### 预览区公式没有渲染？

先检查语法：行内用 `$...$`，独立公式用 `$$...$$`（需独占一行）。`&`、`<`、`>` 等字符可直接书写，软件会自动做 HTML 转义；若存在未闭合的 `$` 或非法的 LaTeX 命令，公式则不会渲染。

### 导出长图 / PDF 没有包含图片？

确保图片可访问。本地文件使用相对路径，网络图片确保网络连接正常。

### 如何打开整个文件夹批量管理文件？

`文件 → 打开文件夹` 选择目录后，侧边栏「文件」面板会以树形展示目录内容，点击即可打开，并在外部改动后自动刷新。
